# Lukas Jasinskas

Building software for infrastructure field crews. I used to be one.

Four years on telecom infrastructure: tower climbing and rigging in the US, leading base station
installations in Germany, then technical design for mobile deployments in Norway. Now I write the
software instead.

## Working on

**Kverna** is an engine that produces telecom site documents, shows where each value came from,
and lists what is missing instead of guessing.
[Read the write-up](https://lukasjas.github.io/blog/kverna/).

## Stack

TypeScript and Python. React on the front, FastAPI and PostgreSQL behind it.
